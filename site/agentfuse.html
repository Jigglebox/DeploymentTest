Setup

# run it (Docker or Node 22)
docker run -p 8787:8787 -e OPENAI_API_KEY=sk-... -e ANTHROPIC_API_KEY=sk-ant-... -e AGENTFUSE_ADMIN_TOKEN=secret agentfuse

# point your agents at it
OPENAI_BASE_URL=https://fuse.yourco.com/openai/v1     OPENAI_API_KEY=af_live_...
ANTHROPIC_BASE_URL=https://fuse.yourco.com/anthropic  ANTHROPIC_API_KEY=af_live_...

What you get

  1. Hard budgets per key: monthly, daily, and per run. Enforced inline on every request, not by a nightly billing export.
  2. Pre-flight blocking. Cost is estimated from prompt size and max_tokens; a call that would cross the cap is refused before it is forwarded.
  3. Loop detection. The same request N times in a window opens the breaker. The key stays blocked until a human resumes it.
  4. Exact metering for streamed and non-streamed responses on both providers, including cached tokens. Every response carries x-agentfuse-cost-usd.
  5. Alerts to Slack or any webhook at 80% of budget, on abnormal burn rate, and on every trip.
  6. Model allow-lists and per-minute rate limits per key.

FAQ

Does it see my prompts?
Self-hosted: nothing leaves your network. Hosted: request bodies are forwarded, never stored; only token counts and costs are kept.
What happens to a blocked call?
HTTP 402 with a JSON error both SDKs surface. The message names the key, the budget, and the resume link.
Streaming?
Passed through byte-for-byte. Usage is read from the stream and metered after the last chunk.
